# QA Checklist

Before considering implementation done, verify:

- Header matches approved desktop design.
- Homepage has no footer.
- Internal pages have shared footer.
- Collection is not a standard grid.
- PDP has concise right-side content.
- PDP Order opens inquiry flow.
- Fashion Film does not load iframe/video until click.
- About uses 2 brand blocks, 1 designer block, cards, process grid.
- Contact has 4 links only: Instagram, LinkedIn, Email, Portfolio.
- Legal pages use sidebar + article layout.
- FR/EN structure exists.
- Content is not hardcoded directly in random JSX.
- No payment/cart/checkout/CMS/database/auth was added.
