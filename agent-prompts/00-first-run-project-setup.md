# Prompt — Project Setup

Set up the project using Next.js App Router, TypeScript, and Tailwind CSS. Read `AGENTS.md` and all files in `project-brief` before implementation.

Do not add payment, CMS, database, cart, checkout, auth, or admin.

Create the project structure for:

- reusable layout components
- typed content files
- FR/EN translation structure
- product data
- forms
- email sending placeholders
- desktop page implementations

Mobile design is not finalized yet, so create responsive-safe structure but do not invent final mobile layouts.
