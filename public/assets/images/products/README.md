# Product images

Each public image belongs to a clear look folder:

- `red-witch/`
- `black-witch/`
- `the-cat/`
- `vaza/`
- `koza/`

`non-used-images/` keeps editorial or multi-look photographs that are deliberately excluded from product and look pages.

All website files are WebP, exported with the longest side limited to 2400 px. Keep original high-resolution photography locally in `assets/new product images/`; that source folder is excluded from Git and deployment. Name future exports by look and purpose, for example `the-cat-hood-portrait-02.webp` or `vaza-embroidery-detail-02.webp`.
