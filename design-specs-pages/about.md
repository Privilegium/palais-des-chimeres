# About Page

## Goal

Present the brand world and designer as an emerging fashion designer profile, not a company page.

## Approved structure

1. Brand block 1
2. Brand block 2
3. Designer block
4. Three approach cards — optional final content
5. Process image grid
6. Shared internal footer

## Layout rules

- Scrollable page.
- More vertical margins between blocks.
- Use refined spacing and calm rhythm.
- Keep text concise.
- Use large images and editorial compositions.

## Brand block 1

Introduce the world of Palais des Chimères.

Short, poetic, not corporate.

## Brand block 2

Manifesto / brand world / craft concept.

Should communicate transformation, memory, ritual, handcraft, sculptural forms.

## Designer block

Dedicated to the designer.

Should feel like:

- emerging designer profile
- graduate collection context
- artistic practice
- fashion design background

Not like:

- corporate founder bio
- agency about page

## Approach cards

Can remain for now, but may be removed later if not approved.

Suggested cards:

- Vision
- Process
- Materials

## Process image grid

Final bottom image section should use process imagery, not only final campaign shots.

Layout:

- 6 images
- 3 per row
- 2 rows
- slightly editorial/chaotic but still clean

Image themes:

- sketching
- draping
- hand embroidery
- fabric handling
- atelier table
- material closeups
