# Product Detail / PDP Page

## Goal

Present one fashion piece as a luxury editorial product page with inquiry-based ordering.

## Approved desktop layout

- Shared header.
- Left vertical thumbnail gallery.
- Large main image.
- Small zoom/plus icon on image.
- Scroll-to-explore indicator.
- Right product information panel.
- Related looks strip.
- Shared internal footer.

## Right panel content

Keep it clean:

- Collection line, e.g. `AW24 — THE BECOMING`
- Product title
- Price, if priced
- Very short 1–2 line description
- Attribute list
- Red `ORDER` button
- Subtle note under button: `Inquiry for this piece`
- Accordion rows: `Details`, `Delivery & Inquiry`

Do not include:

- long description blocks
- separate Description accordion
- long made-to-order explanation below button

## Attribute examples

- Material
- Silhouette
- Collection
- Made to Order

Attributes must be data-driven and may vary per product.

## Inquiry behavior

`ORDER` opens the product inquiry modal.

For request-only products, button label can be `Personal request`.

## Related looks

Show 2–3 related product cards in a horizontal strip.
