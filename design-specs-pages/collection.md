# Collection / PLP Page

## Goal

Display the collection as an editorial fashion catalogue, not a standard product grid.

## Approved direction

Use the first generated collection concept.

## Desktop layout

- Shared header.
- Intro title area.
- Asymmetric product layout.
- Mixed product card sizes.
- Large dramatic images.
- Product name + price or `Personal request`.
- Internal footer.

## Product card states

Priced product:

```txt
Product name
€ price
```

Request-only product:

```txt
Product name
Personal request
```

## Design constraints

Do not implement a uniform 3-column e-commerce grid.

Do not make it look like default Shopify/WooCommerce.

## Interactions

Suggested:

- hover image movement or subtle zoom
- plus icon on card
- click opens PDP
