# 11 — Performance & Media

## Images

- Use optimized image formats.
- Use responsive image sizes.
- Lazy-load below-the-fold images.
- Do not eagerly load all product gallery images.
- Homepage hero should be optimized carefully.
- About process grid images should be optimized and lazy-loaded.

## Video

- Use poster-first loading.
- Do not store heavy video files in `/public`.
- Do not load iframe/player until user clicks `Watch Film`.
- Use fallback poster on mobile / slow connections.

## Icons

Use SVG where possible.

Preferred sizes:

- 24x24 for small UI icons
- 32x32 for contact-link icons
- 64x64 source size for ornaments

## Animation

Keep animations subtle:

- fade-ins
- slow opacity transitions
- hover image movement/zoom
- scroll-to-explore subtle blinking/pulse

Avoid heavy animation dependencies unless explicitly approved.
