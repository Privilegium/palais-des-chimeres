# 13 — Agent Instructions

## Start here

Before implementing, read:

1. `AGENTS.md`
2. `project-brief/14-design-decisions-desktop.md`
3. all files in `/pages`

## Build order recommendation

1. Project setup
2. Design tokens and layout primitives
3. Header and internal footer
4. Home desktop
5. Collection desktop
6. PDP desktop
7. Inquiry modal/form
8. Fashion Film desktop
9. About desktop
10. Contact desktop
11. Legal/text template
12. QA

Mobile is a later phase and should not be invented now unless explicitly requested.

## Do not overbuild

Do not add:

- payment
- CMS
- database
- auth
- cart
- checkout
- admin

## Do not simplify the art direction

Do not turn the site into:

- generic store grid
- generic minimal SaaS layout
- generic corporate page
- generic YouTube iframe page
