# 06 — Design System

## Palette

```txt
Black: primary background
Ivory: primary text
Deep red: CTA, active states, subtle accents
Warm gold: icons and ornaments only
Charcoal: panels / gradients / image overlays
```

## Typography

- Large spaced serif display headings.
- Small uppercase mono/sans-like labels for navigation and metadata.
- Body copy should be elegant, readable, and sparse.
- Avoid large dense paragraphs.

## Shared layout rules

- Header is minimal and centered around the logo.
- Internal pages use shared footer.
- Thin dividers and subtle borders are used throughout.
- Avoid generic rounded SaaS UI.
- Use editorial negative space.

## Buttons

### Primary red button

Used for:

- Order
- Send Inquiry
- Watch Film when appropriate

Visual:

- Deep red fill
- Ivory text
- Wide spacing
- Uppercase label
- Optional arrow

### Secondary / subtle notes

Use low-opacity text for explanatory notes like:

```txt
Inquiry for this piece
```

This should not look like a second button.

## Ornaments

Use sparingly:

- starburst
- thorn divider
- small cross/star markers
- thin flourish dividers

## Form fields

- Dark fields
- Thin ivory/gold borders
- Uppercase placeholder labels
- Minimal dropdown chevron
- Large red submit button

## Footer

Shared internal footer:

```txt
left: PALAIS DES CHIMÈRES — AW24
right: SHIPPING & RETURNS / TERMS / PRIVACY
```

Homepage does not use this footer.
