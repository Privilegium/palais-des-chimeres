# 09 — Video Strategy

## Approved direction

The Fashion Film page is a one-screen cinematic poster-first page.

It should not look like a simple YouTube iframe page.

## Technical rule

Do not host heavy MP4 files directly in the repository or on Vercel.

## Loading strategy

Initial page load:

- poster image / background image
- title
- short description
- watch button
- credits

After click:

- load embedded player
- open modal or fullscreen player
- use YouTube, Vimeo, Cloudflare Stream, Bunny Stream, or equivalent external hosting

## Page behavior

Desktop:

- almost non-scrollable / one-screen experience
- footer visible at bottom

Mobile:

- to be finalized later

## Visual direction

- cinematic background image
- dark overlay
- large serif title
- deep red play button / watch trigger
- minimal credits block
